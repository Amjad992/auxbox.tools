Live at **[auxbox.tools](https://auxbox.tools)**

---

## Tools

### CGPA Calculator

Calculate your cumulative GPA across multiple semesters with a customizable grading system.

**[auxbox.tools/cgpa-calculator](https://auxbox.tools/cgpa-calculator)**

**Features:**
- Calculate CGPA across multiple semesters and subjects
- Customize grade names and point values (supports 0–8 scale)
- Save your configuration and data locally for future visits
- Auto-load saved data on return visits
- Responsive design for desktop and mobile
